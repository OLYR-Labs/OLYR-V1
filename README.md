# OLYR POS

Offline-first point-of-sale software by OLYR Labs.

## Status

Foundation setup is in progress.

## Planned foundation

- Electron desktop application
- React + TypeScript renderer
- Secure Electron IPC
- Local SQLite database
- Windows installer
- Offline-first operation

## Development philosophy

OLYR POS is being built for real-world retail businesses with a focus on speed, simplicity, reliability, security, and graceful hardware failure handling.
